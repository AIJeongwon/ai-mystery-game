# 화면·아트·사운드

근거: `public/index.html`, `public/css/main.css`, `css/scenes.css`, `public/js/ui/`, `public/js/audio.js`, `public/assets/`, `tools/process-art.py`

## 화면 구성

세계지도(Canvas)가 화면 전체를 채우고 그 위에 얇은 틀이 얹힙니다. PC 브라우저 기준이고 휴대폰 화면은 지원하지 않습니다.

| 영역 | 내용 |
|---|---|
| HUD (위, 52px) | 매체명·등급 / 날짜·시각, 속도 단추, LLM 표시등 / 자금, 유료 구독, 독자, 신뢰도, 인주, 기자 레벨, 현재 위치 |
| 도크 (왼쪽, 58px) | 누르면 서랍(392px)이 지도 위로 열립니다. 記定은 도장을 얻기 전, 사건은 제1장 전에는 잠겨 있습니다. 목록은 `ui/drawers.js`입니다 |
| 지도 | 나라, 사건 표식, 내 위치, 지국, 경쟁사 본사, 이동 호, 도장을 찍었을 때 번지는 물결. 모드는 기본 / 관심도 / 정치 안정 / 언론 자유 / 언론 판도 / 내 독자 |
| 오른쪽 패널 (372px) | 평소에는 와이어(세계의 소식이 시간순으로 흐름). 사건이나 나라를 고르면 상세로 바뀝니다. 사건 상세에서 취재 행동, 인터뷰, 수첩, 기사 쓰기를 합니다 |
| 목표 | 캠페인 목표와 항목별 진행, 상황에 맞는 힌트 |

- 서랍 여덟 개: 단서(포착한 사건, 칼럼 쓰기) · 세계(일정표, 의제, 분야별 흐름) · 기사(점수, 조회수, 수익, 데스크 총평) · 경영(개요, 인력, 투자, 기자 역량) · 순위(열 매체) · 記定(장부, 거두기·환원, 각인 강화) · 사건(캠페인 증거와 추리) · 메뉴(음량, 저장, 세이브 내보내기, 도움말).
- 화면 전체를 덮는 것: 타이틀, 인터뷰(질문을 직접 입력하고 근거를 두 개까지 제시), 편집국(종이 지면 모양의 편집기. 수첩 / 제목·본문 / 도장·초안 보조·교열 검토), 발행 결과, 도장 연출, 컷신, 추리·환원 창. 이런 창이 열려 있으면 게임 시계가 멈춥니다.
- 조작: `Space` 일시정지(컷신에서는 다음) · `1` `2` `3` 속도 · 휠과 끌기로 지도 확대·이동 · 나라·사건 표식을 눌러 상세 · `Esc` 닫기 · `Enter` 인터뷰 질문 보내기(`Shift+Enter`는 줄바꿈).

## 시각 방향

**"밤의 편집국과 종이."** 화면 틀은 어두운 남색, 글을 쓰고 읽는 곳은 바랜 종이색, 도장과 강조는 인주의 붉은색(`#e2452f`)입니다. 색은 `public/css/main.css`의 변수로 정의돼 있고, 분야 일곱 가지와 알림의 종류마다 색이 따로 있습니다.

- 화면 문구와 내레이션은 평서체("~다")로 짧게 씁니다. 힌트는 무엇을 누르면 되는지 구체적으로 말합니다. 고유 용어는 낫표(「 」)로 감쌉니다.
- 도장 문양(記定)은 직접 그린 SVG입니다(`public/assets/ui/`).
- 지도는 world-atlas(50m)의 지형을 내추럴 어스 도법으로 투영해 Canvas에 직접 그립니다.

## 에셋

| 종류 | 수와 위치 | 비고 |
|---|---|---|
| 배경 | 16장, `public/assets/bg/` (1920×1086, 합계 약 8MB) | 타이틀과 컷신. `london`, `proof` 두 장은 쓰이지 않습니다(A-11) |
| 초상 | 38장, `public/assets/portrait/` (600×796)과 목록용 축소본 `thumb/` (192×192). 합계 약 5MB | 캠페인 인물 10장 + 범용 28장(권역 7 × 성별 2 × 나이대 2, 파일명 `g_{권역}_{m\|f}{1\|2}`) |

- 54장 모두 이미지 생성 도구(Higgsfield, 모델 `gpt_image_2_6_flare`)로 만든 그림이고, 외부에서 가져온 그림은 없습니다. 화풍은 펜 선 위에 수채를 올린 삽화이며 색을 화면의 청회색·종이색·붉은색 계열에 맞췄습니다.
- 원본을 `tools/process-art.py`로 웹용 크기와 형식으로 가공합니다. 가공 전 원본은 저장소에 없습니다.
- 일반 사건의 취재원은 나라의 권역·성별·나이대에 맞는 범용 초상을 받습니다. 같은 조건이면 같은 얼굴이 나옵니다(A-10).

## 소리

음원 파일이 없습니다. 효과음 21종과 배경 음악 네 가지 분위기(타이틀 / 평소 / 긴장 / 고요)를 모두 WebAudio로 실행 중에 합성합니다(`public/js/audio.js`). 컷신이 분위기를 바꿉니다. 음량은 메뉴에서 효과음과 음악을 따로 조절하며, 브라우저 정책 때문에 첫 입력 뒤에 소리가 시작됩니다. 사람 귀로 들어 조율한 적은 없습니다(B-3).

## 글꼴

화면 글꼴은 Pretendard, 지면과 내레이션은 Noto Serif KR입니다. 글꼴과 지도 라이브러리는 `npm install`로 받아 서버가 `/vendor/`로 내보냅니다. 버전과 라이선스는 [기술 구조](../dev/architecture.md)에 있습니다.

A·B 번호는 [알려진 문제](../roadmap/known-issues.md)의 항목입니다.
