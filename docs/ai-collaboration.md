# AI 협업 운영수칙

팀원은 AI가 작성한 변경도 직접 확인한 뒤 자신의 포크에서 PR로 제출합니다. 작업을 시작할 때 [AI 작업 규칙](../AGENTS.md), [브랜치와 PR 운영](../CONTRIBUTING.md)과 관련 기획을 확인합니다.

- 요청 범위와 수정할 파일을 확인합니다. 다른 사람의 미완료 변경은 보존합니다.
- 팀이 결정한 내용과 제안을 구분합니다. 브랜치 유형, 필수 승인 수, 기술 스택 등을 합의 없이 운영 규칙으로 추가하지 않습니다.
- API·DB·의존성·공통 설정을 바꿀 때는 영향을 받는 코드와 문서를 확인합니다.
- 키·토큰·비밀번호는 저장소, 프롬프트, 로그, PR에 남기지 않습니다.
- 실행한 검사와 결과를 적습니다. 고정 응답으로 확인한 내용과 실제 서비스에서 측정한 결과를 구분합니다.
- AI가 대신 실행하는 커밋·푸시·PR·병합 등은 매번 원본 저장소 소유자의 명시적 승인을 받습니다. PR은 변경 범위와 본문 초안을 먼저 보여주고 승인 후 올립니다. AI 검토와 팀원이 실제로 남긴 리뷰는 구분합니다.
