# 게임 기획

「기정사실(記定事實)」은 기자 경영 시뮬레이션에 세계 개변과 추리 캠페인을 얹은 PC 브라우저 게임입니다. 플레이어는 1인 매체의 기자가 되어 세계지도 위의 사건을 취재하고, 제목과 본문을 직접 써서 발행하며 매체를 키웁니다. 기사 속 한 문장에 **記定 도장**을 찍으면 그 문장은 진실 여부와 상관없이 세상 모두가 원래부터 알던 상식이 됩니다. 그리고 그 도장을 쥔 사람은 플레이어 혼자가 아닙니다.

- 화면: 2D. 세계지도 전체가 게임판입니다. 언어는 한국어입니다.
- 배경: 2031년 3월 3일 오전 8시, 서울 을지로에서 시작하는 가상의 세계. 나라와 도시는 실제 지명이고 인물·기업·기관·언론사는 모두 허구입니다.
- 분량: 프롤로그 「첫 문장」, 제1장 「이미 찍힌 문장」, 끝이 없는 샌드박스.

## 핵심 루프

발견(소문·속보·일정표) → 취재(자료 조사·현장 취재·인터뷰·심층 추적) → 집필(제목·본문을 직접 쓰고, 도장은 한 기사에 한 문장) → 발행(데스크 채점, 단독 판정, 신뢰도 변동) → 정산(조회수 48시간, 광고·구독, 인주 적립) → 성장(등급·투자·인력·지국·각인)

기사 한 건은 게임 속 몇 시간, 투자·채용·지국은 며칠, 매체 등급과 각인은 수십 일의 호흡입니다. 캠페인이 사이사이 다음 단서를 내밉니다.

## 설계 원칙

1. **기사는 플레이어가 쓴다.** 수첩에 모은 사실을 보고 제목과 본문을 직접 씁니다. 도장을 찍을 문장도 플레이어의 문장입니다. 초안 보조는 투자로 열리는 편의 기능입니다.
2. **숫자는 규칙이, 말은 LLM이.** 세계의 수치(나라 사정, 의제, 조회수, 돈)는 규칙 엔진만 바꿉니다. LLM은 사건에 서사를 입히고, 인물로 말하고, 기사를 읽고, 문장의 뜻을 풉니다. LLM의 답은 제안이고 모든 호출에 규칙 기반 대안이 있어, LLM이 꺼져도 게임은 끝까지 돕니다.
3. **도장은 세지만 공짜가 아니다.** 범위와 세기에 한계가 있고, 인주가 들고, 세계에 왜곡이 쌓입니다. 인주는 기사가 읽혀야 차오르므로 도장을 쓰려면 먼저 기자여야 합니다.
4. **세계는 플레이어 없이도 돈다.** 사건은 소문에서 종결까지 저절로 흘러가고 경쟁사가 먼저 보도합니다.
5. **추리의 대상은 '출처 없는 상식'이다.** 캠페인의 수수께끼는 범인 찾기가 아니라, 모두가 알지만 언제 어떻게 알게 됐는지 아무도 말하지 못하는 사실을 찾는 일입니다.
6. **실제 지명, 허구의 인물.** 실존 인물·기업·언론사는 쓰지 않습니다. LLM 프롬프트에도 같은 규칙이 들어갑니다.

## 세 겹의 게임

| 층 | 하는 일 | 끝 |
|---|---|---|
| 샌드박스(경영) | 세계 곳곳의 사건을 취재하고 매체를 키운다 | 없음 |
| 개변(記定) | 문장을 찍어 세계를 바꾸고 그 값을 치른다 | 없음. 샌드박스 위에 얹힌다 |
| 캠페인(추리) | 도장의 내력과 이미 조작된 세계를 추적한다 | 제1장까지. 장은 등록식으로 늘린다 |

캠페인은 샌드박스를 멈추지 않습니다. 캠페인의 무대는 세계지도 위의 특별한 사건으로 놓이고, 평소 취재와 같은 조작으로 진행합니다. 출장비도 평소처럼 듭니다.

## 시간과 실패

- 세계는 30분 단위로 돕니다. 속도는 정지 / 1초에 2분 / 6분 / 20분입니다. 취재·이동·집필은 게임 속 시간을 쓰고, 창이나 컷신이 열려 있으면 시계가 멈춥니다. 자정마다 하루 정산과 자동 저장을 합니다.
- 게임 오버는 없고 실패에 값이 붙습니다. 오보는 사건이 종결될 때 정정보도·법무 비용·구독 이탈로 돌아옵니다. 자금이 한도 아래로 떨어지면 기자가 떠나고, 지국이 닫히고, 신뢰도가 깎입니다. 도장을 함부로 쓰면 왜곡이 쌓여 '집단 기억 불일치' 사건이 생깁니다.

## 용어

| 용어 | 뜻 |
|---|---|
| 記定(기정) | 도장에 새겨진 두 글자. "적어서 정한다." 제목은 '이미 정해진 사실(旣定事實)'과 소리가 같습니다 |
| 기정문 | 도장이 찍혀 세계의 상식이 된 문장 |
| 인주(印朱) | 도장을 찍고 각인을 강화하는 데 쓰는 자원. 기사가 읽힐수록 차오릅니다 |
| 각인 | 도장의 성능 다섯 가지: 범위·강도·지속·동시 유지·은폐 |
| 환원 | 남이 찍은 문장을 풀어 되돌리는 일. 문장과 찍은 사람의 이름이 모두 맞아야 합니다 |
| 왜곡 | 도장을 쓸수록 쌓이는 세계의 뒤틀림 |
| 국면 | 사건의 다섯 단계: 소문 → 발생 → 전개 → 수습 → 종결 |
| 규모 | 사건의 크기 1~5: 지역 / 전국 / 주요국 / 국제 / 세계적 |
| 깊이 | 사실의 깊이 0~3: 공개 / 현장 / 내부 / 핵심 |
| 단독 | 경쟁사보다 깊은 사실을 먼저 쓴 기사. 조회수 배수가 붙습니다 |
| 현지 기반 | 그 나라에서의 발판: 본인 현장(3) / 본사·지국(2) / 파견 기자(1) / 없음(0) |
| 규칙 모드 | LLM 없이 규칙만으로 도는 상태. 키가 없거나 연결이 끊기면 자동으로 넘어갑니다 |
