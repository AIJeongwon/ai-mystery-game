# 알려진 문제와 확인하지 못한 것

고치거나 확인하면 이 문서에서 지웁니다. **번호는 다시 매기지 않습니다**(시험 코드와 다른 문서가 번호로 가리킵니다). 고치는 방법에 여러 길이 있는 항목은 팀이 정합니다 **[미정]**. 우선순위는 [향후 계획](plan.md)에 있습니다.

심각도: **높음** = 만든 내용 일부에 도달할 수 없거나 플레이어가 손해를 봄 / **중간** = 오래 하면 드러남 / **낮음** = 다듬기
