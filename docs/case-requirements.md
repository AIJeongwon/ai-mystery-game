# 사건 설계

이 게임에서 '사건'은 두 가지입니다. 세계가 저절로 만들어 내는 **사건 유형**과, 캠페인이 지도 위에 놓는 **장(章)의 각본 사건**입니다. 각각을 새로 쓸 때 정할 항목을 적습니다. 지금 있는 사건의 내용은 [세계 시뮬레이션](design/world.md)과 [캠페인](design/campaign.md)에 있습니다.

## 세계 사건 유형

`public/js/data/events/<분야>.js`에 항목 하나를 더합니다. 필드 설명은 같은 폴더의 `_helpers.js` 머리에 있습니다.

| 항목 | 정할 것 |
|---|---|
| 분야, `label` | 일곱 분야 가운데 하나(파일이 곧 분야), 화면에 보일 이름 |
| `sig`, `start`, `dur` | 규모 범위(최소와 최대, 1~5), 시작 국면(0 소문 / 1 발생), 국면별 지속 시간 넷(시간) |
| `actor`, `w` | 엮을 행위자의 종류(`gov` / `corp` / 없음), 나라 사정을 받아 발생 가중치를 내는 함수 |
| `impact`, `out` | 종결될 때 세계 수치에 주는 방향, 결말 문구 둘(언론 압력이 높았을 때 / 낮았을 때) |
| `hint` | LLM에게 주는 서사 지침: 무엇이 숨은 사실이고 누가 무엇을 부인하는가 |
| `fb` | LLM이 없을 때 쓰는 규칙 서사 틀. 제목, 개요, 사실 4개 이상(`[깊이, 글]`. 깊이 0과 2 이상이 모두 있어야 함), 거짓 소문, 취재원 2명 이상(`[직함, 태도, 아는 사실 번호, 성격]`) |

- `fb`의 글에는 치환자 `{actor}` `{org}` `{city}` `{country}` `{n1}` `{n2}` `{p1}` `{p2}` `{p3}`만 씁니다. 실존 인물·기업의 이름은 쓰지 않습니다.
- `impact`는 지금 `stab`·`appr`·`econ`·`tens`·`rep`만 세계에 반영됩니다([알려진 문제](roadmap/known-issues.md) A-18). 일정표에 잡히는 유형이면 `data/agendas.js`의 `SCHEDULE_KINDS`에도 넣습니다.
- 파일 안의 항목 순서와 `index.js`가 펼치는 순서가 무작위 뽑기의 순서입니다. 유형을 더하면 회귀 지문이 달라지는 것이 정상이고, 그때는 `node tools/regression.mjs --update`로 기준선을 새로 적습니다.

## 캠페인 장

`public/js/campaign/<장>/` 폴더를 만들고 `campaign/chapters.js`의 목록에 한 줄을 더합니다. 목록의 순서가 진행 순서입니다. 본은 `campaign/ch1/`입니다.

| 파일 | 정할 것 |
|---|---|
| `canon.js` | 미리 찍혀 있는 문장(글, 믿음, 범위, 세기, 효과)과 환원 수수께끼(문장 후보, 찍은 자 후보, 후보마다 필요한 증거, 정답, 인주 비용, 오답 문구) |
| `evidence.js` | 증거: 화면 번호(`no`), 제목, 한 줄 요약(`short`), 열람 본문(`body`) |
| `deductions.js` | 추리: 필요한 증거(`need`), 물음, 선택지, 정답, 오답마다 틀린 까닭(`why`), 맞혔을 때의 문장(`success`) |
| `scenes.js` | 무대가 되는 각본 사건: 장소·분야·규모, 개요와 진상, 사실(깊이, 확보되는 증거 `ev`, 취재원이 말하는 조건 `cond`), 취재원(성격 `persona`, 숨기는 사정 `secret`, 아는 사실 `knows`, 연기 지침 `script`, 직접 가야 만나는지 `onsiteOnly`) |
| `beats.js` | 비트의 배열. 비트는 `enter`(진입 연출), `objective`(제목, 상황별 힌트, 항목별 완료 조건), `watch`(매번 확인할 것), `done`(완료 조건), `exit`(퇴장 연출) |
| `index.js` | 장 객체: `id`, `label`, `beats`. 있으면 `evidence`, `deductions`, `scenes`, `canons`, `finals`(환원 뒤 직접 쓰는 기사), `worldSetup`, `quietDecree` |

- 장 객체의 항목 뜻은 `campaign/chapters.js` 머리에 있습니다. 필요 없는 파일은 뺍니다(프롤로그에는 증거와 추리가 없습니다). 컷신 배경은 `public/assets/bg/`, 초상은 `public/assets/portrait/`와 `portrait/thumb/`에 넣습니다.
- 엔진(`campaign/engine.js`)과 화면에는 특정 장의 내용을 적지 않습니다. 장마다 다른 동작이 필요하면 장 객체에 항목을 더하고 엔진이 읽게 합니다.

## 확인

| 검사 | 보는 것 |
|---|---|
| `tests/content.test.mjs` | 사건 유형의 형식, 규칙 서사 틀, 치환자, 취재원이 없는 사실을 안다고 적히지 않았는지, 분야마다 유형이 있는지 |
| `tests/campaign.test.mjs` | 등록된 모든 장의 비트와 목표 형식, 추리가 요구하는 증거와 정답·오답 까닭, 무대의 사건 유형·나라·의제와 취재원이 아는 사실, 수수께끼 후보와 환원 기사 설정, 그림 파일 |
| `npm run check` | 린트, 시험 전체, 회귀 지문 |
| 브라우저 | 장은 처음부터 끝까지 플레이합니다. 조건부 증언(`cond`)이 LLM 연기로 실제로 나오는지는 자동 시험이 보지 못합니다 |
