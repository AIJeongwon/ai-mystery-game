# 향후 개발 계획

무엇을 어떤 순서로 할지를 적습니다. 문제의 내용은 [알려진 문제](known-issues.md)의 번호로 가리킵니다. 이 문서의 규칙 안과 줄거리 안은 모두 **[제안]**이고, 팀이 정한 뒤 해당 기획 문서에 옮깁니다.

## 순서

| 단계 | 목표 | 주요 작업 |
|---|---|---|
| 기반 | 평가 기준의 컨테이너와 자동 검사를 갖춘다 | 컨테이너 구성과 서버 배포, GitHub Actions 워크플로 |
| 0 | 지금 있는 것을 바로잡는다 | 각인 최고 단계, 감식안, 접속 코드 잠금, 영향 항목 |
| 1 | 만든 것이 실제로 되는지 확인한다 | 제1장 뒤쪽 인터뷰, 긴 플레이, 소리, 비용 실측 |
| 2 | 샌드박스를 오래 해도 마르지 않게 한다 | 의제 순환, 행위자 교체, 경쟁사의 도장, 왜곡의 결과 |
| 3 | 이야기를 잇는다 | 제2장 「지워진 바이라인」 |
| 4 | 더 많은 사람이 하게 한다 | 작은 화면, 접근성, 다국어 |

기반·0·1단계는 서로 기다리지 않습니다. 2단계의 "경쟁사의 도장"은 제2장의 바탕이므로 3단계보다 먼저 합니다.

## 기반

**컨테이너 구성과 배포**: 설계와 진행 순서는 [Docker 구성과 배포](../dev/docker.md)에 있습니다. 컨테이너 구성 → 서버 세이브 → 한도 집계 이전 → 배포의 네 PR로 나눕니다.

**자동 검사 [제안]**: 평가 기준은 서로 다른 검사를 하는 워크플로 5개 이상이고, 포크 PR에서 개인 키 없이 돌아야 합니다. 이 게임의 시험은 LLM 없이 규칙 모드로 돌므로 키가 필요 없습니다. 아직 워크플로 파일은 없습니다.

| 워크플로 후보 | 검사 | 준비 상태 |
|---|---|---|
| 린트 | `npm run lint` | 명령 있음 |
| 시험 | `npm test` | 명령 있음 |
| 회귀 지문 | `npm run regress` | 명령 있음 |
| 장기 구동 | `node tools/balance.mjs 45`가 오류 없이 끝나는가 | 명령 있음 |
| 컨테이너 | 이미지 빌드, Compose 실행, 서비스 간 요청, 볼륨 유지 | 컨테이너 구성 뒤 |
| 문서 | 문서 사이 링크가 끊기지 않았는가 | 도구 선정 필요 |
| 비밀 값 | 커밋에 키·토큰이 없는가 | 도구 선정 필요 |
| 배포 | `main` 병합 뒤 서버에 올림 (원본 저장소에서만 실행) | 배포 뒤 |

## 3단계 — 제2장 「지워진 바이라인」 [제안]

제1장은 복원된 세계시보 1면의 바이라인에 플레이어의 이름이 돌아와 있는 것으로 끝납니다. 줄거리의 답은 정해지지 않았습니다.

- **이 장이 답할 물음**: 플레이어의 과거를 지운 문장은 무엇이고 누가 찍었는가 / 문정호는 왜 도장을 남겼는가 / '발신자 표시 없음'은 누구인가.
- **권장안**: 찍은 사람은 문정호다. 2019년 세계가 모로 보고서를 '조작'으로 알게 되자, 교열부장인 그가 세계시보 마지막 지면의 사과문 한 문장에 도장을 찍어 그 기사에서 후배의 이름을 지웠다. 환원하면 플레이어는 과거를 되찾지만 문정호가 열두 해 동안 대신 진 것이 드러난다. 환원하지 않는 선택도 둔다.
- **이미 게임에 놓여 있어 이 안과 맞물리는 것**: 쪽지의 "찍기 전에는 세 번 읽어라", 수첩의 환원 규칙, 찢긴 바이라인, 제1장 마지막 환원의 '찍은 자' 후보에 든 문정호, 권미옥의 숨은 사정(3월 17일의 인쇄소).
- **다른 안**: 빅토리아 랭이 찍었다 / 제3의 도장 주인이 찍었다 / 플레이어 자신이 찍었다.
- **새로 필요한 것**: 인물마다 플레이어를 다르게 기억하는 장치, 선택에 따른 갈림, 2-3·2-4의 규칙, 각본 사건 5~6개와 증거 20개 안팎, 배경 8장과 초상 5~6장 안팎.

## 4단계 — 넓히기

- **작은 화면과 접근성** (A-16): 좁은 화면 배치, 키보드 조작, 화면 낭독기 표시, 움직임 줄이기.
- **저장**: 세이브 형식 변환(A-6). 크기가 문제면(B-8) `localStorage`에서 IndexedDB로.
- **다국어**: 화면 문구·데이터·캠페인 글·프롬프트가 모두 한국어이고 조사 처리도 한국어 전용입니다. 문구를 코드에서 떼어 내는 일부터 합니다.
- **배포한 뒤 검토할 것**: 사람별 접속 코드, 플레이어가 자기 키를 넣는 방식, 규칙 모드 전용 체험판(GitHub Pages).
