| 일정 | 내용 |

기능별 담당자, 기술 스택과 주차별 작업 범위는 팀에서 합의한 뒤 기록합니다. 공통 API와 데이터 형식이 달라지면 영향을 받는 담당자와 변경 내용을 공유합니다.

## 외부 LLM API 사용 계획

게임 서버가 외부 LLM API를 호출합니다. 개인 API 키는 게임 서버의 환경 변수로 전달합니다. 브라우저와 저장소에는 키를 넣지 않습니다.

| 용도 | 사용할 정보와 응답 |
|---|---|
| NPC 인터뷰 | 플레이어의 질문에 NPC가 답합니다. |
| 엔딩 회고 | 플레이어의 취재 과정, 발행한 기사, 발행 후 세계에 일어난 변화를 바탕으로 회고를 작성합니다. |

팀원 개인 프로토타입에서는 NPC 대화 응답에 약 1~3초가 걸렸습니다. 사용한 모델 ID와 테스트 조건은 담당자의 실행 설정을 확인한 뒤 기록합니다. 게임 서버 연동 후에는 인터뷰와 엔딩 회고의 응답 시간을 각각 확인합니다.

월 제공 크레딧 범위에서 사용할 예정입니다. 크레딧이 소진되거나 API 요청이 실패했을 때 게임 화면에서 어떻게 안내할지는 팀에서 정합니다.
