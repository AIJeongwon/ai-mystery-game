# 「기정사실」

플레이어가 기자가 되어 기사를 발행하면 그 내용이 현실이 되는 게임입니다. NPC 인터뷰, 현장 조사, 사진 촬영으로 사실을 확인할 수도 있고, 취재 없이 기사를 발행할 수도 있습니다.

- **선택 취재** — 어떤 사건을 얼마나 취재할지 직접 정합니다.
- **기사 발행과 세계 변화** — 기사 내용이 현실이 된 뒤의 변화와 조회수, 독자 반응, 기자의 인지도를 확인합니다.
- **엔딩 회고** — LLM이 취재 과정과 기사 발행이 세계에 미친 영향을 플레이 기록에 따라 되짚습니다.
