# 사건 설계

하나의 사건을 설계할 때 다음 항목을 구분해 적는 방식을 제안합니다.

| 항목 | 정리할 내용 |
|---|---|
| 발행 전 상황 | 사건의 배경과 실제로 일어난 일, 관련 인물과 각자가 알고 있는 사실 |
| 취재로 확인한 내용 | 인터뷰 진술, 현장에서 관찰한 점, 촬영한 사진과 각각의 출처. 취재를 생략한 경우에도 기사를 발행할 수 있습니다. |
| 발행한 기사 | 플레이어가 사건에 대해 실제로 보도한 내용. 취재로 얻은 정보와 다른 주장을 담을 수 있습니다. |
| 발행 후의 변화 | 기사의 어떤 내용이 현실이 되었고 누구에게 어떤 변화가 생겼는지, 기사에 대한 독자 반응은 어땠는지 |
| 엔딩 회고에 쓸 기록 | 플레이어가 취재한 내용과 발행한 기사, 그 결과를 연결해 회고할 수 있는 기록 |

기획을 검토할 때는 같은 사건에서 **취재한 뒤 발행하는 경우**와 **취재 없이 발행하는 경우**를 각각 따라가 봅니다. 두 경우 모두 발행 전의 사실, 기사에 실린 주장, 발행 뒤의 결과를 구별할 수 있어야 합니다.

사건 수와 세부 설정은 팀에서 정합니다. 전체 흐름과 논의할 사항은 [게임 기획](game-design.md)을 참고합니다.
